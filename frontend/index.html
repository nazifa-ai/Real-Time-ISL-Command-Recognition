CLASS-LEVEL EVIDENCE

Per-sign model analysis

Each sign is compared on the same held-out test clips for all trained models.

50-sign comparison

Precision, recall, within-sign accuracy*, F1, support and measured single-sequence latency.

* Within-sign accuracy is the fraction of held-out clips of that sign recognised correctly; mathematically this equals recall. Latency is model-only, measured on clips whose true label is that sign. The test set has only 3–4 clips per sign, so estimates are directional. Rows are NOT live-webcam scores.

Signer-independent accuracy

NOT EVALUATED

Lighting robustness by sign

NOT EVALUATED

LIMITATIONS & OVERSIGHT

Responsible AI

Designed for a supervised classroom prototype; not a replacement for a fluent ISL interpreter.

Privacy & security

  • Camera permission is requested by the browser. Frames are processed in memory by the local API and are not saved.
  • Only predictions and human feedback are written to local JSONL audit files; no raw video is retained.
  • Use localhost for a local demo. Public deployment requires authentication, restricted origins and HTTPS.

Known evaluation gaps

  • Vocabulary is the 50 isolated signs in AI4Bharat INCLUDE-50; grammar and continuous signing are outside scope.
  • Signer-independent accuracy: not evaluated; the dataset has no signer IDs.
  • Per-sign lighting robustness: not evaluated; the available robustness suite perturbs extracted landmarks, not image brightness.
  • Accessibility feedback: not yet established through a participant study. Human correction buttons provide operational feedback only.
